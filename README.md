# Grocery Price Analysis Dashboard 📊

## Overview

This project analyzes grocery prices across major South African retailers to compare pricing trends, identify the most affordable stores, and monitor monthly price changes.

The dashboard was created using **Microsoft Excel** for data cleaning and preparation and **Power BI** for interactive data visualization.

## Objectives

* Compare grocery prices between retailers
* Identify the cheapest and most expensive stores
* Track monthly price changes
* Present insights through a professional dashboard

## Tools Used

* Microsoft Excel
* Power BI
* Data Cleaning
* Data Visualization
* Dashboard Design

## Dataset Information

The dataset contains grocery product prices collected across four retailers:

* Checkers
* Pick n Pay
* Shoprite
* Woolworths

Period Covered:

* January 2026
* February 2026
* March 2026

Products Included:

* Bread
* Milk
* Eggs
* Rice
* Oil
* Sugar
* Toiletries
* Cleaning products
* Beverages
* Household essentials

## Process

### 1. Data Cleaning (Excel)

* Removed inconsistencies
* Standardized product names
* Checked missing values
* Structured dataset into table format

### 2. Dashboard Creation (Power BI)

Built interactive visuals including:

* Price comparison by retailer
* Monthly trend analysis
* Average price by store
* Highest and lowest priced items
* Category insights

## Key Insights

* Shoprite had the lowest average prices across most products.
* Woolworths had the highest average pricing.
* Several essential grocery items increased in price over the 3-month period.
* Household and cleaning products showed noticeable price growth.
